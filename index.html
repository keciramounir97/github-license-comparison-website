DevOps & Git Version Control Guide

Step-by-step repository initialization, public vs private repository comparison, and the complete .gitignore ecosystem.

Step 1

Repository Creation & Initialization

Execute standard CLI commands to initialize, stage, commit, rename branch, and link to GitHub/GitLab remote.

$git init# Initialise un nouveau dépôt local .git
$git add .# Indexe l'ensemble des fichiers dans la staging area
$git commit -m "Initial commit: production architecture"# Fixe le snapshot initial
$git branch -M main# Définit explicitement la branche principale 'main'
$git remote add origin https://github.com/votre-compte/votre-depot.git# Relie au dépôt distant
$git push -u origin main# Pousse vers 'main' et configure l'upstream tracking
Step 2

Public vs Private Repository Matrix

Security, visibility, collaboration models, and CI/CD minutes quota evaluation for team governance.

Dimension / Critère Dépôt Public (Open Source) Dépôt Privé (Propriétaire / Confidentiel)
Visibilité & Indexation Visible par tous les internautes, indexé sur Google et le moteur de recherche GitHub. Invisible au public. Strictement réservé aux membres autorisés et audité en interne.
Sécurité & Secrets Risque élevé en cas de fuite de clés API ou secrets dans l'historique de commits. Protection des secrets confidentiels, politiques de conformité ISO/SOC2 et audits stricts.
Collaboration & Modèle Modèle Fork & Pull Request ouvert à la communauté mondiale. Étoiles et visibilité RH. Gestion des accès basée sur les rôles (RBAC/IAM), branches protégées et revues d'équipe.
CI/CD & Quotas GitHub Actions Minutes GitHub Actions 100% gratuites et illimitées sur les runners standards. Quotas mensuels plafonnés (ex. 2 000 min/mois en compte gratuit), puis facturation à l'usage.
Cas d'usage Recommandés Bibliothèques open source, frameworks, documentations publiques, vitrines techniques. Code métier propriétaire, SaaS internes, microservices critiques, R&D confidentielle.
Step 3

.gitignore Universe & Templates

From ActionScript and Ada to Node.js, Python, Rust, and Go, plus standard IDE and OS exclusion patterns.

Historiques (ActionScript & Ada)

  • ActionScript: bin-debug/, *.swf, *.swc, .actionScriptProperties
  • Ada: *.ali, *.o, gnat/, b~*.ad[sb]

Écosystèmes Modernes

  • Node.js / TS: node_modules/, dist/, npm-debug.log
  • Python: __pycache__/, *.pyc, .venv/, *.egg-info
  • Rust / Go: target/, Cargo.lock, bin/, vendor/
  • C / C++: *.o, *.obj, build/, CMakeCache.txt

IDEs & Systèmes d'Exploitation

  • VSCode & JetBrains: .vscode/* (sauf extensions), .idea/
  • macOS: .DS_Store, .AppleDouble
  • Windows: Thumbs.db, desktop.ini, $RECYCLE.BIN/
  • Environnement: .env, .env.local, *.pem
